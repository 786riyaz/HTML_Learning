# Semantic vs Non-Semantic HTML Tags

## Semantic Tags
- **Meaningful** → Clearly describe the purpose of the content  
- **SEO Friendly** → Help search engines understand page structure  
- **Accessibility** → Improve usability for screen readers  
- **Examples** → `<header>`, `<footer>`, `<article>`, `<section>`, `<nav>`  

---

## Non-Semantic Tags
- **Generic** → Do not convey specific meaning  
- **Styling Purpose** → Commonly used for layout and design  
- **Not SEO Friendly** → Do not help search engines understand structure  
- **Examples** → `<div>`, `<span>`, `<i>`, `<b>`  

---

## Common Semantic Elements
There are many semantic elements available in HTML. Some commonly used ones include:  
`<article>`, `<aside>`, `<details>`, `<figcaption>`, `<figure>`, `<footer>`, `<header>`, `<main>`, `<mark>`, `<nav>`, `<section>`, `<summary>`, `<time>`

---

## Body Structure Tags
These tags define the overall structure of a webpage:  
`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`

---

# Detailed Explanation of Key Semantic Tags

## `<header>`
- **Purpose** → Contains introductory content or navigation links  
- **Semantic** → Adds meaning to the enclosed content  
- **Location** → Usually at the top of a page or section  
- **Flexibility** → Can also contain `<article>` or `<section>`  
- **Multiple Use** → Can be used multiple times on a page  

---

## `<main>`
- **Purpose** → Represents the primary content of the webpage  
- **Semantic** → Clearly defines the main content area  
- **Unique** → Should appear only once per page  
- **Accessibility** → Helps screen readers identify main content  
- **Restriction** → Should not include repeated elements like navbars or footers  

---

## `<section>`
- **Purpose** → Groups related content into sections  
- **Semantic** → Provides structure and meaning  
- **Headings** → Typically includes `<h1>` to `<h6>`  
- **Nested** → Can be nested inside other `<section>` or `<article>` tags  

---

## `<article>`
- **Purpose** → Contains independent, self-contained content (e.g., blog post, news article)  
- **Semantic** → Adds contextual meaning  
- **Independence** → Should make sense even when taken out of the page  
- **Multiple Use** → Can appear multiple times on a page  

---

## `<aside>`
- **Purpose** → Holds sidebar or supplementary content  
- **Semantic** → Indicates content related but not central  
- **Non-Essential** → Not critical to understanding the main content  
- **Examples** → Widgets, quotes, advertisements  

---

## `<footer>`
- **Purpose** → Contains footer-related content  
- **Semantic** → Adds meaning to the enclosed content  
- **Location** → Typically at the bottom of a page or section  
- **Content Includes** → Copyrights, contact info, social links  
- **Multiple Use** → Can be used multiple times on a page
