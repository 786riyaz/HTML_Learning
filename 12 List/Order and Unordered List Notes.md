# Ordered and Unordered Lists in HTML

---

## Ordered List (`<ol>`)

### Purpose
- Used for creating lists where the **order of items matters**

### Features
- **Default Behavior** → Items are automatically numbered  
- **Nesting** → Can be nested inside other lists  

---

## Types of Ordered Lists

| Type                  | Format Example        | Attribute        |
|----------------------|----------------------|------------------|
| Numeric (Default)    | 1, 2, 3, ...         | `type="1"`       |
| Uppercase Letters    | A, B, C, ...         | `type="A"`       |
| Lowercase Letters    | a, b, c, ...         | `type="a"`       |
| Uppercase Roman      | I, II, III, ...      | `type="I"`       |
| Lowercase Roman      | i, ii, iii, ...      | `type="i"`       |

---

## Example Outputs

### Uppercase Letters
A. Apple  
B. Banana  
C. Cherry  
D. DragonFruit  

### Lowercase Letters
a. Apple  
b. Banana  
c. Cherry  
d. DragonFruit  

### Uppercase Roman
I. Apple  
II. Banana  
III. Cherry  
IV. DragonFruit  

### Lowercase Roman
i. Apple  
ii. Banana  
iii. Cherry  
iv. DragonFruit  

---

## Unordered List (`<ul>`)

### Purpose
- Used for lists where **order does not matter**

### Features
- **Default Behavior** → Items are displayed with bullets  
- **Nesting** → Can be nested inside other lists  

---

## Types of Unordered Lists

| Type        | Description        | Example Style |
|-------------|------------------|---------------|
| Disc        | Default solid dot | ● Item        |
| Circle      | Hollow circle     | ○ Item        |
| Square      | Solid square      | ■ Item        |
| None        | No marker         | Item          |

---
