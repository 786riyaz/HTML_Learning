# Browser Developer Tools

## View Page Source
- Displays raw **HTML and CSS** of the webpage  
- Useful for **learning and debugging**  
- Shows **external file references** (e.g., JavaScript, CSS links)  

---

## Inspect Element
- Allows **real-time editing** of HTML and CSS  
- Useful for **testing and debugging UI changes**  
- Displays **DOM structure (element hierarchy)**  
- Shows **layout, styles, and box model**  
- Includes **JavaScript Console** for running scripts and debugging  
- Highlights the **selected element directly on the webpage**
