# 📁 First HTML Project Setup Guide

## 🛠 Step-by-Step Instructions

1. **Create a Folder**

   * Create a folder named **`First Project`** on your Desktop

2. **Open Notepad**

   * Launch Notepad (or any text editor)

3. **Create HTML File**

   * Create a new file
   * Save it as **`index.html`**

4. **Add Sample Code**

   * Copy and paste the following code into your file:

```html
<!DOCTYPE html>
<html lang="en">
    <head>
        <meta charset = "UTF-8">
        <meta name="viewport" content="width=device-width, initial-scale=1.0">
        <title>Document</title>
    </head>
    <body>
        <h1>This is my First HTML Code</h1>
    </body>
</html>
```

5. **Run the File**

   * Open the file in any browser (Chrome, Edge, etc.)
   * You will see your first HTML page

---

## 💡 Alternative: Using VS Code

You can also run your HTML file using an IDE like **VS Code**:

### Steps:

1. Open the folder in VS Code
2. Right-click on `index.html`
3. Click **"Open with Live Server"**

> 🔥 This will automatically open your page in the browser with live reload support

---

# 📄 Importance of `index.html`

1. **Default Homepage**

   * It is the default file loaded when visiting a website

2. **First Impression**

   * Acts as the main entry point for users

3. **SEO Benefit**

   * Helps search engines understand your site structure

4. **Standard Convention**

   * Provides a consistent starting point across web servers

5. **Fallback Behavior**

   * Loaded when no specific file is mentioned in the URL
