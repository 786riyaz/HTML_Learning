# Basics of HTML

---

## 📁 File Extensions

### HTML

- Most commonly used
- Works across all browsers
- Widely recognized and supported
- Typically saved as `.html`

### HTM

- Less commonly used
- Originated for compatibility with older systems
- Works the same as `.html`
- Typically saved as `.htm`

---

## 🏷️ HTML Tags

- Elements used to create a website are called **HTML tags**
- Tags can contain content or other HTML tags
- Used to define elements like text, images, and links

---

## ⚡ Using Emmet (`!` Shortcut)

1. Open your IDE (e.g., VS Code)
2. Save the file with `.html` extension
3. Type `!`
4. Select the suggestion to auto-generate HTML boilerplate

---

## 📄 Basic HTML Page Structure

```html
<!DOCTYPE html>
<!-- Define the HTML Version -->
<html lang="en">
  <!-- Root element -->
  <head>
    <!-- Metadata container -->
    <title>My First WebPage</title>
    <!-- Page title -->
  </head>
  <body>
    <!-- Main content -->
    <h1>Hello World!</h1>
    <!-- Heading -->
  </body>
</html>
```

## 💬 Comments in HTML

- Used to add notes in HTML code
- Not visible on the web page
- Syntax: `<!-- Comment -->`
- Helps in code organization
- Can be single-line or multi-line

---

## 🔤 Case Sensitivity

- HTML is **case-insensitive** for tag names
- Attribute names are also case-insensitive
- **Best practice:** use lowercase for consistency

### Examples:

```html
<html> = </HTML>
<p> = </P>
<head> = </HEAD>
<body> = </BODY>
```
