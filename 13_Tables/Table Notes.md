# HTML Table Elements

---

## Basic Table Tags

### `<tr>` — Table Row
- Defines a **row** in an HTML table  

### `<th>` — Table Header
- Defines a **header cell** within a row  
- **Default Style** → Bold and centered text  

### `<td>` — Table Data
- Contains the **actual data** inside table cells  

---

## Caption (`<caption>`)

### Purpose
- Provides a **title or description** for a table  

### Key Points
- **Placement** → Must be placed immediately after the `<table>` opening tag  
- **Default Alignment** → Centered above the table  
- **Accessibility** → Helps screen readers understand the table’s purpose  

---

## Colspan Attribute

### Attribute
- Used as `colspan` in `<td>` or `<th>`  

### Purpose
- Allows a cell to **span multiple columns horizontally**  

### Key Points
- Occupies the space of the specified number of columns  
- Useful for creating **complex table layouts** by merging cells
