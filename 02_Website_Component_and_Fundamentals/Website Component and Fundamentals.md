# 🌐 Client Side vs Server Side

## ⚙️ Execution Location

* **Client Side** → Executes on the user's device (browser)
* **Server Side** → Executes on a remote server

## 💻 Languages

* **Client Side** → JavaScript, HTML, CSS
* **Server Side** → PHP, Python, Java, Node.js, etc.

## 🎯 Main Job

* **Client Side** → Handles UI interactions (clicks, scrolls, animations)
* **Server Side** → Manages data, business logic, and storage

## 🔐 Access Level

* **Client Side** → Cannot directly access server files or databases
* **Server Side** → Can read/write files and interact with databases

## ⚡ Speed

* **Client Side** → Faster for UI updates (no server round-trip)
* **Server Side** → Slower due to network latency

# 🌍 Role of Browser

```
HTML, CSS, JavaScript  →  Downloaded by Browser  →  Rendered  →  Displayed to User
```

## Key Responsibilities:

1. **Display Web Page** → Converts HTML into visual UI
2. **User Interaction** → Handles clicks, typing, scrolling
3. **Dynamic Updates** → Updates content using JavaScript
4. **Load Resources** → Fetches HTML, CSS, JS, images from server

---

# 🧱 HTML (HyperText Markup Language)

1. **Structure** → Defines layout of web page
2. **Content** → Adds text, images, links
3. **Tags** → Uses elements like `<p>`, `<a>`, `<div>`
4. **Hierarchy** → Organizes elements in a tree structure

---

# 🎨 CSS (Cascading Style Sheets)

1. **Styling** → Controls appearance of elements
2. **Colors & Fonts** → Customizes text and backgrounds
3. **Layout** → Manages positioning and sizing
4. **Selectors** → Targets specific HTML elements

---

# ⚡ JavaScript

1. **Not Java** → Completely different from Java
2. **Interactivity** → Handles dynamic behavior
3. **DOM Updates** → Changes content without reloading
4. **Events** → Responds to user actions (click, hover, input)
5. **Data Handling** → Communicates with server (APIs, fetch)
